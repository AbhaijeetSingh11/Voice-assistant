# Voice Assistant Project

**Goal:** Build an end-to-end voice assistant with speech recognition, NLU, and TTS.

## Day 1: Setup & Scaffold

1. Initialize GitHub repo: add LICENSE, .gitignore.
2. Create Python virtual environment and install base dependencies.
3. Scaffold folder structure and boilerplate files.

### Getting Started

```bash
# Clone and enter repo
git clone https://github.com/AbhaijeetSingh11/Voice-assistant.git
cd voice-assistant

# Create & activate virtual environment (Linux/macOS)
python3 -m venv venv
source venv/bin/activate
# (Windows PowerShell)
# python -m venv venv
# .\\venv\\Scripts\\Activate.ps1

# Install dependencies
pip install -r requirements.txt
